# Document Copilot

A full-stack GenAI application for analyzing SEC filings with citations.

## Tech Stack
- Backend: FastAPI + Python
- Frontend: React + Vite + TypeScript
- Database: Supabase (PostgreSQL + pgvector)
- LLM: OpenAI
- Deployment: Railway

## Features
- Ask questions about SEC filings
- Answers grounded in source documents
- Inline citations [1], [2], etc.
- Supports Apple, Microsoft, NVIDIA, Amazon filings
